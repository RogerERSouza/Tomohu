# Tomohu 0.19.0 — Frontend feature modules

## Scope and baseline

Baseline: merged main at `161960c` (0.18 backend authentication milestone). This release reorganizes the frontend and adds regression coverage. The frontend remains a local-storage app; API accounts and synchronization are planned for 0.20. Backend code, migrations, deployment configuration and database data are unchanged.

App.tsx is reduced from 1,614 lines to 133 lines of composition. Forms, cards, page views, preference effects, collection selection, notebook actions, persistence and backup I/O have explicit owners. See [ADR 0002](../architecture/0002-frontend-feature-modules.md).

The storage key `task.notebook.v1`, schema version 1, theme/hour preference keys, hash routes, styles, and confirmation behavior are preserved. The only intentional visible change is the Settings version label, now sourced from package.json as 0.19.0 instead of the stale 0.17.0 literal. No new product feature or data migration is included.

## Executed validation — 2026-11-09

Environment: Linux, Node 24.22.1, npm 11.9.0, Playwright 1.65.0 and headless Chromium 153. Browser locale is pt-BR and timezone is America/Sao_Paulo; scenarios use isolated browser contexts and a fixed clock.

The browser checks were established in two runs (26 existing-flow checks plus six additional checks) against the unchanged source. The three extracted form bodies and five moved feature component bodies were also compared through TypeScript's AST printer: all matched the baseline. Existing domain helpers and styles are unchanged.

## Reproduce on Windows

Run from the repository root after applying the patch:

```powershell
npm.cmd ci
npm.cmd run lint
npm.cmd run format:check
npm.cmd test
npm.cmd run build
npm.cmd run typecheck
npx.cmd playwright install chromium
npm.cmd run test:e2e
```

The browser command builds and starts its own production preview on port 4173. Docker and Uvicorn are not needed for these checks. Use `npx.cmd playwright show-report` to inspect results; the CI workflow retains reports/traces on failures. `npm.cmd run dev` remains the normal development command.

## Limits and recovery

Chromium's standard Playwright download was unavailable in the implementation environment, so browser runs used a separately supplied Chromium 153 through `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`. CI installs Playwright's pinned Chromium normally. No completed remote CI run for this release is claimed. Mobile viewport emulation is not a physical Android/iOS test; Firefox, WebKit and the owner's Windows environment have not been verified here. Automated coverage supports the listed flows; it is not a guarantee for every possible input or browser.

The backend is untouched and its suite was not rerun for this frontend release. The existing 0.18 PostgreSQL validation record remains applicable to that unchanged code.

Export a backup before validating a release with personal data. If rollback is needed after merge, revert the release commit through a PR; the unchanged schema remains readable by the baseline frontend. Do not clear browser storage. Existing local-only/multiple-tab and invalid-storage recovery policies remain unchanged; synchronization and any policy changes require a separate delivery.
